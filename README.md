# Bingo Digital 🎲

Aplicativo offline de bingo para eventos locais — desenvolvido por **Martins Labs**.

✅ Totalmente funcional no navegador  
✅ Sem necessidade de internet  
✅ Modo operador + modo exibição  
✅ Geração de cartelas em PDF  
✅ Tema claro/escuro  

Ideal para igrejas, escolas, quermesses, bares e festas beneficentes.

---

## 🚀 Como usar

1. Abra `public/index.html` no navegador (com Live Server ou duplo clique)
2. Escolha **Modo Operador** para controlar o sorteio
3. Abra **Modo Exibição** em outro dispositivo/telão para mostrar ao público
4. Clique em "Sortear Número" — a tela de exibição atualiza automaticamente!

---

## 🛠 Tecnologias

- HTML5, CSS3, JavaScript puro (ES6+)
- jsPDF (via CDN) para exportação
- localStorage para estado offline
- Totalmente responsivo e acessível

---

## 📦 Futuro

- Versão executável (.exe) com Electron
- Autenticação simples (Firebase Auth)
- Customização de regras (75 vs 90 números)
